A one-sentence roast for the [make.fun](https://make.fun) bounty
"The Long Roast: Lawmakers and the File They Cannot Convert": a senator
writes the law forcing AI companies to disclose their source code, yet
cannot turn his own bill into a PDF — the Word file is password-protected
and the only person who knew the password retired in 2019.

The program (`main.py`, Python standard library only) writes that single
sentence to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`
when `OUTPUT_DIR` is set). The entry is a single sentence, 1–320
characters, with no trailing newline, and the program asserts those
gates before writing.
